Live URL = https://ai-seo-rank-tracker-fronend.vercel.app

Full-stack application using MongoDB, Express.js, React.js and Node.js. Browser base for browser automation and website scraping, and Gemini AI for intelligent SEO analysis and report creation. Engineered real-time ranking history monitoring with interactive analytics and automated AI-driven SEO recommendation reports.

Features in this project 🔥

✅ Website SEO Analyzer Tool <br>
✅ AI SEO Report Creator <br>
✅ Monitor Keyword Rankings <br>
✅ Browserbase for Browser Automation <br>
✅ Embed Gemini AI <br>
✅ MERN Stack Auth <br>
✅ Database Integration MongoDB <br>
✅ REST API Development <br>
✅ Deployment - Vercel application


<b>How to Run Project </b>
In Vs Code

1. Open backend folder in Integrated terminal <br>
   npm install <br>
   npm run server <br>
   add all environmental variables in <b>.env</b> file <br>
   <br>


2. Open Frontend folder in Integrated terminal <br>
   npm install <br>
   npm run dev <br>
   add all environmental variables in <b>.env</b> file <br>
<br> <br>
<b>Deploy both Frontend and Backend file separately on Vercel.  </b>
